# Examples

Runnable programs that are not part of the library. Each one is a directory with
its own README; run them from the repository root.

| | |
| --- | --- |
| [`topology_quickstart/`](topology_quickstart) | The smallest adaptive-topology run: three agents, one strategy string, one report. `--dry-run` needs no LLM. |
| [`dig_in_action/`](dig_in_action) | The DIG paper's real-time interaction-graph figure, drawn live from a running `Ensemble`. Offline, no API key. |
