# Security Policy

## Supported versions

Security fixes go into the latest release only. Upgrade to the latest version on PyPI before reporting.

## Reporting a vulnerability

Please do not open a public issue. Report it privately through [GitHub's vulnerability reporting](https://github.com/idea-idsia/ant-ai/security/advisories/new) and include:

- the affected version,
- what an attacker can do,
- steps or code to reproduce it.

We follow up in the private advisory, ship the fix in a new release, and then publish the advisory, crediting you unless you ask us not to.

Vulnerabilities in a dependency should be reported to that project. Report them here only if the way ant-ai uses the dependency makes it exploitable.
